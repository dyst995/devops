# Tasks — Numbers

Close `theory.md`. Recite types, then prove in the REPL.

1. [ ] **Memorize:** three built-in numeric types: `int`, `float`, `complex`. Immutable. `bool` is not a fourth on this list.
2. [ ] **Write:** `int` examples — whole, negative, `int(3.9)`, `int("10")`, `int("10", 2)`. No fixed max.
3. [ ] **Write:** `float` — `3.14`, `2e3` → `2000.0`, `float(10)`, `float("1.5")`.
4. [ ] **Memorize:** `/` of two ints → float; `//` → floor int. Mixing int+float in `+` `*` → float.
5. [ ] **Learn:** `0.1 + 0.2` may not be `0.3` (IEEE-754 / C double). One sentence.
6. [ ] **Write:** `3+4j`, `4j`, `.real` `.imag` (floats), `complex(3, 4)`, `complex("1+2j")`. Unit is **`j`**.
7. [ ] **Memorize** the three-row table (class / example / conversion). `str(x)` on each.
8. [ ] **Write:** `1 / 2`, `1 // 2`, `int(3.9)` — three results from memory.
9. [ ] **Learn:** `n = n + 1` is a **new** int object. Optional `id` proof.
10. [ ] **Memorize (cover):** `int`/`float`/`complex`; `j`; `/` vs `//`; `2e3`; `int("10", 2)`.
