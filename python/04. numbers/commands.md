# Commands to memorize

```python
# three built-in numeric types: int, float, complex

type(10)                 # int
type(3.14)               # float
type(3 + 4j)             # complex

int(3.9)                 # 3
int("10")                # 10
int("10", 2)             # 2
float(10)                # 10.0
float("1.5")             # 1.5
1 / 2                    # 0.5  (float)
1 // 2                   # 0    (int floor)

z = 3 + 4j
z.real                   # 3.0
z.imag                   # 4.0
complex(3, 4)            # (3+4j)
```
