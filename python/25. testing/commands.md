# Commands to memorize

```text
Script → maintainable app

Continuous delivery
  = automatically releasable to production at any time
  = build pipeline: test + deploy (test env + production)

Automate everything
  build · tests · deployment · infrastructure

Traditional testing
  deploy to test env + black-box UI clicks (+ test scripts)

Manual = time-consuming, repetitive, tedious
  repetitive → boring → mistakes
  remedy = automation

Automated suite
  no click protocols
  large refactor → know in seconds

Quality gates     — pipeline checkpoints; red = stop
Test pyramid      — many unit · fewer integration · few UI/e2e
Code quality tools
Additional tools  — more automated gates, not a one-off script
```
