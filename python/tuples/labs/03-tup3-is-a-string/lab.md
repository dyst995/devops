# tup3 is a string

`tup3 = "a", "b", "c", "d"` (no parentheses) must be a **tuple** of four strings, same idea as `list3` but immutable.

`tup0 = ()` is empty. `(1)` must not be confused with a one-item tuple.

**Goal:** `type(tup3)` is `tuple`. `tup0` is empty. Show `(1,)` vs `(1)`. Ordered: swapping items is a **different** tuple (like lists), but you cannot fix order with item assignment.
