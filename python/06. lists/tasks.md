# Tasks — Lists

Close `theory.md`. Recite characteristics, then write the course snippets.

1. [ ] **Learn:** list = comma-separated objects in **`[]`**. Mixed types OK (`list1`). Recite `list1` `list2` `list3`.
2. [ ] **Memorize:** ordered — `[1,2,3,4] == [4,1,3,2]` is **False**. Nested OK. Empty `[]`.
3. [ ] **Write:** `a = ['foo', … 'corge']` — `a[0]`, `a[-1]`, `a[1:4]` (same slice rules as strings).
4. [ ] **Write:** nested `x`. Memorize `x[1]`, `x[1][0]`, `x[1][1]`, `x[3]`, `x[3][0]`.
5. [ ] **Write:** `list1[2] = 2001`; `del list1[2]`. Mutable in place.
6. [ ] **Memorize:** `+` `*` `in` `len` `max` `min` `sum` `sorted` (new list).
7. [ ] **Memorize methods:** `append` `count` `extend` `index` `insert` `pop` `remove` `reverse` `sort` / `sort(reverse=True)`.
8. [ ] **Write:** `extend([4,5,6])` vs `append([4,5,6])` — length and last item. Memorize the trap.
9. [ ] **Learn:** missing `index` / `remove` → `ValueError`. `pop()` last; `pop(0)` first.
10. [ ] **Memorize (cover):** order matters; `x[1][1]`; extend vs append; `sort` in place vs `sorted` new.
