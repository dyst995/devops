# Tasks — pip

Close `theory.md`. Recite, then type in a **venv**. Prefer `python -m pip`.

1. [ ] **Learn:** pip = installer; default index PyPI; installs into **that** interpreter’s site-packages.
2. [ ] **Memorize:** `python -m pip` vs bare `pip`. No `sudo pip` on OS Python.
3. [ ] **Write:** create, activate, deactivate a venv for **your** OS. Prove `python` is inside `.venv`.
4. [ ] **Memorize:** `install` / `==` / range / `--upgrade` / `uninstall` / `list` / `show` / `freeze`.
5. [ ] **Write:** upgrade pip; install a package; `show` location; uninstall.
6. [ ] **Write:** `freeze > requirements.txt` then new venv `install -r`. Recite freeze **out**, `-r` **in**.
7. [ ] **Learn:** `--user` vs venv. `--index-url` **replaces** default; `--extra-index-url` **adds**.
8. [ ] **Memorize:** pip ≠ pyenv. `pip search` is gone.
9. [ ] **Write:** prove wrong `pip` vs `python` (`pip --version` vs `python -m pip --version`).
10. [ ] **Memorize (cover):** `-m pip`; venv trio; list/show/freeze; `-r`; index-url vs extra.
