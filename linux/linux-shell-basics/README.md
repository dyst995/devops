# Linux Shell Basics — Study Pack

How to use this folder:

1. Read one **theory** file.
2. Close it and answer the matching **questions** file without looking.
3. Check yourself against the **Answers** section at the bottom of the questions file.
4. Repeat the questions you missed the next day.

This pack follows [linux/intro](../intro/README.md) (what a shell is). Here you learn what Bash runs **when it starts**, how the shell works as a **language**, the editors you will use on every server, and the **basic commands** you should be able to type without looking them up.
