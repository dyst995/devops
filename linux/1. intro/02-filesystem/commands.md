# Commands to memorize

```bash
chmod +x script.sh           # turn on execute bit — Linux does not care about .sh
mount /dev/sdb1 /mnt/data    # attach a disk/partition onto a directory in the single tree
lsblk                        # block devices and their mount points
df -h                        # disk space used/free, human-readable
findmnt                      # what is mounted where
```
