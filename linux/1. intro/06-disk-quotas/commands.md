# Commands to memorize

```bash
# fstab: usrquota,grpquota on the mount     # enable quota accounting on that filesystem
quotacheck               # scan the FS and build/update quota files
quotaon                  # turn quotas on
edquota                  # edit a user’s/group’s soft/hard limits (interactive)
setquota                 # set limits non-interactively
repquota                 # report usage vs limits (admin)
quota                    # show quota for the current (or named) user
```
